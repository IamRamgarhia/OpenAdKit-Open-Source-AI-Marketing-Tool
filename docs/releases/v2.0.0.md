## What's new in OpenAdKit 2.0

OpenAdKit 2.0 is the biggest update yet: a real desktop app you install in one step, a connector for Claude and Cursor, safer syncing, and no more made-up numbers.

### Install it like any other app

- **Native Windows app.** Download `OpenAdKit-Windows-Setup.exe`, double-click, done. It installs for your user only (no admin password), opens in its own window, and includes everything it needs — no Node.js, git or build step.
- **One line for macOS and Linux.** Paste one command into Terminal. It checks every download against a SHA-256 checksum, uses your Node.js or fetches its own, and adds **OpenAdKit.app** on a Mac or an app-menu entry plus an `openadkit` command on Linux. Uninstalling keeps your data.

### Much faster

Rebuilt on **Next.js 16, React 19 and Tailwind CSS 4**. The installed app runs the production server, so it starts in about 1–3 seconds instead of compiling pages on first load.

### Use OpenAdKit inside Claude Desktop, Claude Code and Cursor

New **MCP server** with 30 AI tools (18 generators, 11 optimizers, competitor research) plus your saved client brands. It works **without an AI key** — Claude writes the result and OpenAdKit checks it, including platform character limits — or with your own key, where OpenAdKit generates and validates by itself. The installers can connect it to Claude Desktop for you. Setup guide: [docs/MCP.md](https://github.com/IamRamgarhia/OpenAdKit-Open-Source-AI-Marketing-Tool/blob/main/docs/MCP.md).

### Update notifications

The installed app tells you when a new version is out (**"OpenAdKit vX is available"**, once a day, can be turned off in Settings). On Windows it updates in one click — it downloads the new installer, checks its checksum and installs it silently. On macOS and Linux, run the install line again.

### Sync you can trust

Folder sync now merges row by row. An edit made in one window is no longer overwritten by an older copy, and a client or ad you delete stays deleted instead of coming back. API keys and the key vault are never written to the sync file.

### No made-up numbers

- A/B test sample sizes are calculated with the standard two-proportion formula from your own baseline and target lift.
- Budget projections are computed from your CPC, conversion rate and order value — or from clearly labelled benchmark midpoints.
- The Creative Score CTR band is labelled as an AI estimate.
- Ad prompts only use proof and numbers that are in your Brand Brain.
- Every AI result is checked against its schema, with one automatic correction if needed.

Claude **Sonnet 5.5** (new default), **Opus 5.5**, **Haiku 5.5** and **Fable 5.2** added with current prices, so the cost counter is accurate. Truncated or refused replies from any provider are now reported clearly instead of showing as empty output.

### Bug fixes

A long list of fixes across the app. The ones you're most likely to notice:

- macOS / Linux start and stop scripts failed when run from the wrong folder — they now work from anywhere.
- Restarting from the control panel on macOS / Linux could kill the new server.
- Edits could be reverted and deleted clients could come back after a sync.
- A client without an id could be duplicated on every sync.
- Suggestions no longer make a paid AI call every time you open the page.
- The launch wizard no longer cuts off healthy, slow streams after 90 seconds.
- Several research and strategy pages could crash on unexpected AI output — now handled safely.
- Budget planner crashed on some daily amounts; batch mode now runs two clients at a time.
- Campaign Print / PDF works again; CSV export includes the generated text and is protected against spreadsheet formula injection.
- The budget hard stop now applies to every AI call, not just some screens.
- The website reader and local sidecar are hardened against slow-HTML and DNS-rebinding tricks.
- Offline mode shows a proper "you're offline" page instead of the wrong screen, and the offline cache no longer grows forever.

Full technical list: [CHANGELOG.md](https://github.com/IamRamgarhia/OpenAdKit-Open-Source-AI-Marketing-Tool/blob/main/CHANGELOG.md).

### Known limitations

- **The Windows installer is not code-signed yet**, so Windows SmartScreen may say *"Windows protected your PC"*. Click **More info → Run anyway**.
- **The macOS / Linux install script has been tested on Linux** (fresh install, update, tampered download refused, uninstall in a clean Ubuntu container). Macs use the same script, but it hasn't had the same testing on a Mac yet — if anything goes wrong on your Mac, please [open an issue](https://github.com/IamRamgarhia/OpenAdKit-Open-Source-AI-Marketing-Tool/issues/new).
- **AI output quality depends on the model you choose.** OpenAdKit checks structure and character limits, but a small free model will write weaker copy than a large one.
